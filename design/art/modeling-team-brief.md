# 第 1 部分　5 分钟读懂这个游戏 🔴

> 推翻任何东西之前，请先吃透这一部分。这是游戏的灵魂，不是美术风格问题。

## 1.1 一句话

> **1–4 人第一人称合作游戏。你们经营一家濒临破产的"地表回收事务所"，替火星上的有钱人，到被瘟疫污染、被遗弃的地球废墟里，冒死回收"真实的地球旧物"。**

身份基调一个词：**Municipal Debt Noir（市政欠债黑色电影）**。

## 1.2 世界观（2098 年）

- 富人移民去了**火星**——干净、安全、封闭、昂贵的世界。穷人、负债者、低信用人口被**留在地球**。
- 火星上流短暂回过地球（葬礼、慈善晚宴、遗产拍卖），却带回了一种火星适应性病原体 **MRC-7**，民间叫**"贵客瘟疫"**。它感染人、动物、植物、真菌、土壤——地球出现了感染人群、变异动物、肉质植物、孢子雾、**会模仿声音的真菌群落**，大片区域沦为封锁区。
- 从此火星富人不再亲自回地球，但他们**仍然想要地球的东西**。火星什么都能合成，唯独缺**"真实的地球"**：真花、真土、真旧生态标本、真污染、真危险。
- 于是他们通过离岸平台、轨道货运公司、灰色中介，向地球发布**回收委托**。地球底层应运而生一个新行业：**地表回收事务所**。**玩家就是其中一家，快破产了。**

## 1.3 玩家是谁

不是英雄，不是军队，不是探险队。**就是一家破公司。** 办公室很小，一半日光灯不亮，墙皮在掉，电脑是火星淘汰下来的二手 CRT 终端，楼下停着一辆二手货车。员工没几个，设备很烂，欠着一屁股债。唯一值钱的，是一张快过期的**地表回收许可证**。

玩家接活不是为了拯救世界，是因为：**不接活就还不上债 → 还不上债公司就被收购 / 许可证被吊销 → 那就连地球上仅剩的一点都没了。**

## 1.4 核心调性（最重要，别做歪）

> **表面轻松好笑，笑完之后不舒服。**

- 幽默，但笑过之后发凉。
- 荒诞，但内部逻辑严密。
- 故事不靠大段叙述，靠**合同、扣款条款、客户备注、结算单**自己说话。
- 不是英雄史诗，是**底层外包工的日常**。

**标志性瞬间**（整个游戏的核心意象）：玩家拼死从冰封疗养院取回一朵变异雪莲，结算单上写着——

```
雪莲完整度：87%
冷链保存：通过
舱内污染费：已扣
轨道检疫费：已扣
人员冻伤补贴：无
客户用途：阿瑞斯穹顶区某私人晚宴的餐桌中央装饰
客户反馈：花粉造成的轻微灼伤增强了"真实感"
```

地球人拼命取回的雪莲，火星客人拿去**装饰晚宴餐桌**。游戏不需要说"富人很坏"——合同会说，扣款会说，客户用途会说。

## 1.5 核心循环（你们建的所有东西都服务于它）

```
HQ 办公室（接活 / 买装备）
   → 全队登上派遣货车
   → 车内运输（过场）
   → 任务现场（搜刮 / 部分撤离的抉择）
   → 货车返回
   → HQ 结算（讽刺在这里落地）
```

三个关键玩法时刻：**①出发前**读客户委托、猜他想要什么 → **②现场**在时间和**载重上限**压力下，决定带什么、丢什么 → **③结算**揭晓你猜得多对 / 多错。

## 1.6 三条不可逾越的红线 🔴

1. **不抄 Lethal Company。** 它只是"低保真合作恐怖"这个**品类与生产方法**的参照（强仪式、低成本可读的布景、合作撤离张力、有清晰导航的黑暗）。凡是它截图里能看见的——飞船、怪物、UI、终端、道具表、地图——**一律不得复制**。我们共享品类语言，不共享它的资产。
2. **可玩性与合理物理尺度，优先于视觉装饰。** 家具、角色、怪物、车辆、门、道具、碰撞体，必须在 Unity 里**物理上说得通**。1.75m 的工人就是 1.75m，门要进得去，车要开得动。
3. **讽刺靠系统，不靠说教。** 火星富人**绝不**做漫画式的反派演讲。越是礼貌、专业、公事公办的客户语气，讽刺越强。

# 第 2 部分　我们目前走到的美术方向 🟡（参考，可质疑 / 改进）

> 这一整部分是"现状参考"。你们可以认同它、改进它，或在概念图里提出替代方案。
> 但请注意：**配色与调性是全局识别**，大改动请先和 PM 对齐。

## 2.1 一句话风格定位

> **低保真工业恐怖（Lo-Fi Industrial Horror）：低多边形、强剪影、可见纹素的低分辨率贴图、强光池 + 暗角的可读黑暗、廉价公共机构的旧与脏。**

**是**：低模几何、平面 / 简单材质、脏旧的旧公共设施。
**不是**：①半写实 PBR（扫描级微细节、1K 贴图）②极端 PS1 像素恐怖（不做顶点抖动 / 仿 CRT 全屏滤镜）③卡通 / 高饱和。

## 2.2 美术总测试（贴在显示器上）

> **「如果它看起来属于一个运转良好、有钱、干净的机构，它就不属于这个游戏。」**

每个资产都问一句：**它能在一个长期缺钱的政府设施里撑过五年吗？** 能，就对了；不能，就不对。

## 2.3 配色系统（带 hex）

**表面色 = 灯光照上去之前的材质色。不是为了好看选的，是一个采购员从目录里按最低价批量买的。**

| 色族 | 场景占比 | 主要 hex | 用在哪 |
|---|---|---|---|
| 混凝土灰 | **60%** | `#5E5E5E` / `#707070` / `#4A4A4A` | 墙、地板、柱子、大体量 |
| 军绿 | **20%** | `#55624A` / `#68745C` / `#475040` | 金属柜、货车车体、铁皮家具、储物柜 |
| 旧木棕 | **15%** | `#6B5440` / `#7C624A` / `#8A7158` | 桌、书架、台面 |
| 锈 | **5%** | `#7B4B2A` / `#8C5937` / `#A36842` | 管道接缝、柜子下缘、螺栓——只出现在水 / 摩擦 / 失修**物理上说得通**的位置 |

**点缀色（极克制，几乎只用作灯光，不用作大面材质）：**

| 点缀 | hex | 唯一允许的用法 |
|---|---|---|
| 暖钨丝橙黄（主点缀） | `#FFAB40`–`#FF8C00` | **灯光**：吊灯、台灯、暖光工作灯。代表"有人住 / 有人来过"。**货车内部和断电的任务现场禁止出现暖光。** |
| CRT 绿（次点缀） | `#6CFF5F` | **只准电子屏幕**及其 0.5m 内的微弱溢光（电脑、探测仪、出口灯）。禁止上墙 / 地面 / 环境光。 |
| 印章红 | `#C23A2B` | **只准纸面 / 标识**（"逾期""违约"印章）。绝不发光，绝不上生物。 |
| 陈旧安全黄 | `#C8A020`–`#A87E10` | **只准材质**（地面警示条、台阶边、栏杆）。永远是脏的、刮花的。 |

> **关键**：颜色不是价值信号。可捡拾物全部用统一的陈旧大地色，**不要**用颜色标"这个值钱"。

## 2.4 灯光（只有三种）

5000K 冷白 / 3000K 钨丝暖 / CRT 绿。**没有彩色点光、没有霓虹、没有镜面铬。** 黑暗靠"强光池 + 必须留出的暗区"实现，且**出口永远是亮的**——难的是"选择走不走"，不是"找不找得到出口"。

## 2.5 形状语言

> **每个形状都是为了"实用、便宜、好修"做的。没有任何形状是因为"被设计过"而存在。**

矩形统治一切，五种几何原型：**板（slab）/ 框（frame）/ 管（tube）/ 面板（plate）/ 螺栓组合件（bolted assembly）**。允许的曲线只有：排水孔、管弯、磨圆的边角——都是"用出来的"，不是"雕出来的"。**刻意雕的有机曲线不允许**（唯一的现存例外见 5.2 HQ 的火星壳，且那本身就是"待你们重审"的对象）。

剪影测试：把道具转成纯黑剪影、缩到 64×64px，问——**两个字以内能叫出名字吗？**（"文件柜""灭火器""台灯"）能，就合格。

## 3.2 每张图必须表达的内容

**概念图 A — HQ 内景**
- 巨大冰冷的空间 vs 角落里廉价温暖的人窝（这种"对比"是 HQ 的核心，详见 5.2）。
- 暖钨丝灯只在人窝；CRT 终端的绿光是全场唯一"活信号"；债务板的压迫；那辆被照料得最好的货车。
- 情绪：**焦虑的义务感，不是恐惧**——这里的威胁是财务的，不是物理的。

**概念图 B — 烂尾楼内景**
- 公共机构的空旷与失败感：失效的日光灯、被搬空的痕迹、渗水、感染从边缘侵入。
- 一个"强光池 → 必须的暗区 → 远处一点 CRT 绿"的导航节奏。
- 一处"不对劲的细节"（错误的尺度 / 错误的内容 / 错误的状态）——这才是恐怖所在。

**概念图 C — 角色 + 装备 + 怪物**
- 三名队员：**临时工气质**——没一样东西是自己挑的，全是发的。头部要有区分（安全帽 / 毛线帽 / 硬壳帽 / 兜帽），靠剪影区分而非颜色。
- 手持装备：手电、医疗包、设备箱、夹板（见 5.5）。
- **回声霉菌**：1.8m 上下的感染人形真菌宿主；比例 / 站位"不对"；唯一暖色信号是 amber-orange `#FF6A00` 的孢子眼点（见 5.6）。

## 3.3 交付与评审

- **形式**：2D 概念图（手绘 / 数字绘 / 拼贴均可）。目的是**敲定风格**，不是出工程图。
- **数量**：每个选题 1 张主图；如有不同风格方向，可一题多版供 PM 选。
- **评审人**：PM（David）最终拍板。把"现有方向（第 2 部分）"和你们的提案**并排**呈现，讲清你们改了什么、为什么。
- **通过标准**：①能让陌生人答出"低保真合作恐怖游戏"而不是"写实游戏草稿" ②同一帧里找得到至少一个本作身份元素（市政色板 / 公文 / 欠债标语 / 钨丝橙黄）③PM 认可调性没有跑偏（第 1 部分的灵魂）。

# 第 4 部分　建模规则与技术规范 🟡

> 这部分技术性较强，是 Unity 工程与性能的现实约束，建议遵守。
> 数值可以讨论，但"低保真 + 强剪影 + ≤256px 贴图"的总方向请先和 PM 对齐再改。

## 4.1 面数预算（三角面）

| 资产类型 | 三角面预算 | 备注 |
|---|---|---|
| 小道具（瓶 / 书 / 工具 / 杯） | **20–300** | 剪影承担主要工作 |
| 门 / 柜 / 桌 / 中型家具 | **100–800** | |
| 人形（玩家 / NPC） | **700–2500** | 角色拿全项目**最低**预算 |
| 怪物 | **1000–4000** | 剪影 + 比例错位讲故事，不靠面数 |

**原则**：模块化套件建图；**先形体后细节**；在玩法尺度和构图成立之前，禁止写实微细节。

## 4.2 贴图与材质

| 项 | 规则 |
|---|---|
| 分辨率 | 墙 / 地 / 顶大面 **≤256px**；道具 **≤256px**。可见纹素颗粒是**特征**，不是缺陷。 |
| 通道 | **只用 Albedo（基础色）**。**不做** normal / AO / metalness 微细节贴图——金属感用**颜色 + smoothness** 表达。 |
| 粗糙度 | 高粗糙，**smoothness ≤ 0.3**。没有光泽塑料、没有镜面。 |
| 平铺 | 世界尺度锚定，约 **2m 一个循环**。 |
| 脏旧 | 暴露表面必须带脏旧（颜色变体 / 贴图颗粒 / 角部积尘）。干净平色只准出现在叙事上"新换的 / 精装的"表面。 |

## 4.3 尺度、轴向、导出

- **单位**：1 Unity unit = 1 米。**真实尺度**——人 1.75m、门 ~2.1m、桌 ~0.75m、货车按真车。建模时就按米建，别事后缩放凑。
- **轴向**：Unity 是 **Y-up、Z-forward、左手系**。Blender（Z-up）导 FBX 时勾选 **-Z forward / Y up**，并 **Apply Transform / 应用缩放与旋转**，避免进 Unity 后躺倒或缩放错乱。
- **导出格式**：**FBX**（项目现有管线为 Blender → FBX → Unity）。其他 DCC 也走 FBX，规范通用。
- **原点 / 轴心**：放在物体"自然落地 / 自然挂接"的点（家具在底面中心，门在铰链边），方便代码对齐与吸附。
- **法线 / 三角化**：导出前三角化、重算法线；UV 不重叠（除非刻意平铺）。

- **深区：封存集装箱区（sealed container bay）** — 大量集装箱、封条 crate、起重设备、**被分类打包的地球遗物**（真相碎片：火星返程徽记、早于官方通告的日期标签）

**风格**：工业废土里的公共机构式套件**放大版**——更大体量、更多金属与传送带、更多"流水线打包"的冷酷感。终局图，气氛最沉。

**🔍 层二私人遗物（情感锚点 · 提议 3–4 件，⚠️ 待 PM 定叙事后细化）**
> 主题：**东西被打包送走 + 真相收束**（终局图）。层二在这里兼任**真相碎片**载体。

| 遗物（提议） | 对应谁的命运 | 检视细节 |
|---|---|---|
| 一份装运清单 | 某批"地球遗物"被编号打包送往火星——人的记忆变成货号 | 火星收件地址 + 编号 2098-XXX |
| 货运工的家书 / 工牌 | 亲手打包地球记忆送走的工人，自己也是回不去的地球人 | 工牌 + 一封没寄出的信 |
| 早于官方通告的检疫记录 | 证明火星早知瘟疫来源，却写成"地表自源"（真相碎片） | 日期栏早于官方通告数年 |
| 被退回的私人信 | 想往火星给移民亲属寄信的地球人——地球人无权往火星寄 | 退回章"无投递权限" |

## 5.6 道具系统（三类，别混淆）

> **特别澄清**：手电筒是玩家**带去的手持装备**，**不是**地图掉落物。下面三类分开建。

**A. 手持装备（玩家带去的快捷栏道具 / 工具）**
| 装备 | 说明 | 优先级 |
|---|---|---|
| 手电筒 Flashlight | 核心。黑暗导航，每局必用。已有基础版可重做。 | P0 |
| 医疗包 / 诱饵 / 喷雾 | 基础快捷栏三件 | P1 |
| 夹板 / 设备箱 / 线缆卷 | 角色默认手持物，立角色气质（概念图 C 也用） | P1 |
| A镜（分析镜 Analysis Lens） | 后期商店道具，看精确状态百分比 | P2 |

**B. 可捡拾物（搜刮目标，是核心循环的主体）— 双层架构**

> **为什么分两层**（同类作品调研结论）：物品的情感**不来自"读它的内容"**，来自**类别的私密性 + 客户用途的反差 + 视觉痕迹**——《This War of Mine》里你读不到信，但知道自己在偷一对老夫妇的药。所以纸片不能当搜刮主体撒量，拆成两层。

**层一 · 搜刮经济主体 —— 视觉化"物件"（看模型就能判断价值，扛现场取舍）**
> 借《致命公司》的方法（不抄资产）：强剪影、有体积、有重量、性价比可感。统一陈旧大地色，**价值不显示在物上、结算才揭晓**（=《Moonlighter》卖时才揭晓）。**高复用、做变体、撒量。**

| 类目 | 载重 | 复用范围 | 优先级 | 例 |
|---|---|---|---|---|
| 器物 / 摆件 | 中 | 全图通用 | P0 | 陶瓷、钟表、乐器、装饰件 |
| 家用科技 / 家电 | 中 | 全图通用 | P0 | 坏电器、终端、小家电 |
| 专业工具 / 器械 | 中 | 全图通用 | P0 | 工作器械、仪器 |
| 个人衣物 / 随身物 | 轻–中 | 全图通用 | P1 | 衣物、包、鞋、配饰、证件 |
| 医药 / 药械 | 轻–中 | 多图常见 | P1 | 处方瓶、器械 |
| 宗教 / 礼仪器物 | 轻–中 | 多图常见 | P1 | 家用神龛、仪式物 |
| 酒 / 奢侈消费品 | 中 | 图偏向（会所） | P1 | 酒瓶、奢侈品 |
| 本土植物标本 | 中 | 图偏向（自然 / 医疗） | P1 | 容器装植物、土芯 |
| 住宅家具 / 固定件 | 重 | 图偏向（住宅） | P1 | 家具段、灯具、招牌（双手抬） |

**每个 P0 类目先做 3–5 个剪影各异的变体**撑搜刮密度（载重：轻=1 / 中=2 / 重=4）。

**层二 · 情感 / 语境锚点 —— 私人遗物（少而精，手工，可检视）**
> "地球遗物"主题的灵魂，但**不是刷子物**。靠**视觉私密性 + 检视举起看痕迹 + 结算客户用途反差**承载，**不靠玩家读全文**（=《Edith Finch》：物品靠视觉细节讲故事，不靠长文）。**每张图手工放 3–6 件独特的、对应那张图的人的命运；不撒量、不做通用变体。**

| 类目 | 载重 | 怎么承载情感（不靠读字） |
|---|---|---|
| 私人信件 | 轻 | 手写信封 + 收件人名字（检视可见） |
| 家庭照片 | 轻 | 裱框全家福、照片里模糊的脸 |
| 儿童物品 | 轻 | 蜡笔画、作业本、磨损的玩具 |
| 日记 / 家庭影像 | 轻 | 翻开停在某一页 |
| 公文 / 制度物 | 轻 | 欠债通知、公章、委托表——也是本作标志性的"公文感"道具 |

**🔍 检视系统（PM 已定要加）**：捡起任意可捡拾物可**举起旋转查看细节**。对层二尤其关键——"举起一件别人的遗物端详"本身就是"我在翻别人人生"的私密、愧疚体验，把"读不到内容"变成"看得到痕迹"。**建模要求**：层二遗物贴图用满 256px 上限，关键细节（手写名字 / 照片的脸 / 玩具磨损）要在检视距离可读。

> 客户系统（哪类客户偏好什么、怎么定价）是策划那边的机制，你们不用管——建模这边只要照"**层一撒量、层二少而精**"来做就对了。

**C. 纯装饰散落物（堆密度氛围，不可捡，P2）**
坏工具、空容器、垃圾、纸堆、缠绕线缆、破家电——按"密度寄存"讲"这里有人用过"；多与 5.1 通用散件共用。

## 5.7 怪物：回声霉菌（Echo Mold）🟡 + 变体 🟢

> **已经建好并导入项目**（1.8m，含 4 段动画）。新人**不必从零做主怪**，可以做它的变体、或以后给别的地图设计专属怪物。

- **它是什么**：MRC-7 感染的人形真菌宿主，浑身菌伞与孢子，蹒跚游荡。危险不在力气，而在**它偷听并回放你们对讲机里的人声**——用队友的声音从错误方向喊"我找到了，过来！"，把队伍引散。
- **造型规则**（即便放开为真菌怪也要守）：比例 / 站位"不对"；本体移动安静；**第一警报是行为 / 听觉**（孢子噗噗声、回放的金属失真感），近距离才以 amber-orange `#FF6A00` 孢子眼点作"确认"；**不**关灯、不制造黑暗事件。
- **新怪物方法论**（art-bible 怪物框架）：先**命名一种压力**（这个机构里工人 / 访客承受过什么压力）→ 找它的**物质形态**（纸、账本、工牌、维修工具……）→ 把**比例做错** → 守色板 → 信号只用琥珀橙眼。名字来自工作（"核查专员""收债员"），不是怪物学。
- ⚠️ **怪物是核心玩法**，新怪物的设计请先和策划 / PM 对齐，再动手建模。

# 第 6 部分　UI / UX 可参与项 🟡🟢

> 你们如果有 UI 能力，这块也能帮上忙。核心审美一句话：**UI 不假装是游戏 HUD，它假装是"公文"。**

**文档层测试**：每个 UI 元素都问——**它能用一台政府办公室的黑白复印机 + 一个橡皮图章复印出来吗？** 需要渐变 / 投影 / 圆角 / 发光 / 动态模糊才成立的，就重做到不需要为止。

- **面板**：单线右角框，无圆角、无投影、无玻璃感。源自 A4 比例、印章块、表单字段、文件夹标签、收据条、账本行。
- **字体**：等宽 / 打字机 / 衬线板式字体（配 CRT 与公文）；标题大写、加宽字距；数字用 tabular 对齐（账本要对齐）。**禁止**斜体（强调用下划线）、投影、发光、渐变、混排字体。
- **图标**：①印章块（重边框矩形 + 大写短词）②勾选 / 账本记号（`[ ]` 待办 `[X]` 完成 `[-]` 失败）③装备线描图标（快捷栏，32×32px 单色可读）。**禁止**彩色编码图标、像素风、待机时还在动的图标。
- **动效**：全部来自旧办公设备的物理行为——CRT 预热、收据机走纸、图章落下。机械、功能性、短、可打断。**禁止**默认控件淡入滑入、弹簧 / 回弹曲线、UI 抖屏。
- **关键屏**：HQ 电脑终端（4:3，CRT 绿 `#6CFF5F` on 黑 `#0A0A0A`）/ 任务 HUD（最小占屏，目标用公文语气）/ 结算账本（逐行打字机动画，赤字用会计括号 `(¥4,575)`，成功**不庆祝**——字体不变，办公室只是"处理"）。
