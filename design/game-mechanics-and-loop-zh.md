## 1. 核心循环 LOOP

### 1.1 一天的大循环

```
HQ 办公室
  ① 在办公电脑接活（读客户委托）/ 买装备
  ② 全队登上派遣货车
  ③ 车内运输（过场）
  ④ 抵达任务现场 —— 搜刮 + 随时决定"还走不走"
  ⑤ 货车返回
  ⑥ 回 HQ 结算（讽刺在这里落地）
```

### 1.2 现场里的小循环（每个任务内）

```
搜散物 → 装满车 → 判断什么时候撤 → 结算揭晓你猜得多对
```

**三个关键玩法时刻：**
1. **出发前**：读客户委托，猜他偏好哪类东西。
2. **现场**：在**载重上限** + **越待越危险/越脏**的双重压力下，决定带什么、丢什么、何时撤。
3. **结算**：揭晓每件东西的价格 + 客户用途（讽刺）。

> 核心张力不是计时器，是 **载重 12 单位装不下 + 危险/感染随时间上升** 的双重挤压。

## 2. 三种任务类型（道德滑坡）

| 类型 | 中文 | 客户偏好（钱） | 结算讽刺 | 道德基调 |
|---|---|---|---|---|
| Free Salvage | 自由采集 | 无，全部市场价 | 中性市场估价，无客户语气 | 中性——只是交房租 |
| Commissioned Job | 指定委托 | 偏好 1–2 个**大类** ×1.3 | 每件有客户用途备注 | 讽刺——用途在结算落地 |
| Black Commission | 黑色委托 | 同上 | 同机制，客户身份/用途牵连更大 | 黑暗——高薪 + 暗黑代价 |

**结局只有两种**（🔒 锁定 D-A/D-G）：
- **成功 Success**：任何**自愿撤离**（哪怕空车）。
- **失败 Failure**：**全员倒地**。
- **没有"部分成功"**。"少拿安全撤 vs 多拿冒险"是连续的取舍，不是一次性目标。

## 3. 进度骨架：许可证 4 阶段 + 地球恶化 5 级

**两条独立的进度轴同时跑：**

| 许可阶段 | 名称 | 解锁 | 情绪 |
|---|---|---|---|
| 1 | 临时采回许可 | 基础委托 | 只想还债 |
| 2 | 正式采回许可 | 更怪的客户；**自由采集解锁** | 这些人在消费地球 |
| 3 | 特殊样本转运许可 | **黑色委托解锁**（高薪暗黑） | 活越来越脏 |
| 4 | 移民资格审查 | 结局抉择门：去火星 / 留地球 | 你还想去吗 |

- 故事任务解锁门槛：完成 **4 / 10 / 18** 个任务（🎛）。
- **地球恶化等级 1–5**：随**总任务数**推进（与许可阶段独立），驱动每月安全成本上涨。
- **许可证被吊销 = game over**（火星资本在你无法维持安全标准时收回许可，不是竞争对手收购）。

## 4. 搜刮系统（核心玩法）

### 4.1 载重（车队共享）

| 项 | 值 | 标记 |
|---|---|---|
| 车队共享载重上限 `vanWeightCapacity` | **12 单位**（范围 8–20） | 🎛 |
| 轻 Light | **1 单位** | 🔒 |
| 中 Medium | **2 单位** | 🔒 |
| 重 Heavy | **4 单位** | 🔒 |
| 每人口袋（装轻物）`lightItemPocketSlots` | **2 格**（1–3） | 🎛 |

- 重物 = 双手抬；中物 = 单手；轻物 = 可入袋。
- 一件重物 = 4 单位 = 默认上限的 1/3 → 每拿一件重物都是"要不要丢掉已装的 3 件轻物"的决定。
- 装满后拒绝新物，必须主动卸下才能腾位。

### 4.2 物品状态（3 档，乘进价格）

| 状态 | 系数 | 含义 | 标记 |
|---|---|---|---|
| 完好 | **×1.0** | 封存、干净、无损 | 🔒 |
| 一般 | **×0.7** | 轻微积尘、陈旧 | 🔒 |
| 受损 | **×0.4** | 物理/水/结构损伤（**最差，是底**） | 🔒 |

**初始状态由环境决定：** 封存房/高架 → 完好；开放走廊/标准房 → 一般；积水区/深感染区近怪巢 → 受损。

**降一档的触发（受损是底）：**
- 贵重物（`baseValue ≥ 80` 🎛）在**车外"硬脱手"**：倒地时掉落 / 被怪打掉 / 高处摔 / 抛给队友。**放进车货区、有意轻放 → 不降级。**
- 捡物时该玩家**感染暴露 > 70** 且在**深区** → 降 1 档（见 §8）。

**A镜（分析镜）**：后期商店道具，让状态从"三档标签"细化到**精确百分比 0–100%**，议价更精准。

### 4.3 双层物品（2026-06-26 拍板）

> 物品的情感不来自"读内容"，来自"类别私密性 + 客户用途反差 + 视觉痕迹"。所以拆两层：

**层一 · 搜刮经济主体（视觉化"物件"）** —— 扛"重量 vs 价值"取舍
- 每图生成 `itemsPerMapInstance` = **10–14 件**（8–18，🎛）。
- 每个 P0 类目先做 **3–5 个剪影各异的变体**。
- 走**大类偏好**：4 大类 = **家居烟火 / 劳作器械 / 自然遗存 / 文化信仰**。

**层二 · 情感锚点（私人遗物）** —— 每图手工 `relicsPerMap` = **4 件**（3–6，🎛）
- 不撒量、不做通用变体；靠视觉私密 + 检视 + 结算反差。
- 信 / 照片 / 儿童画 / 日记 / 公文。

### 4.4 客户偏好（决定价格倍率）

| 倍率 | 默认 | 范围 | 作用 | 标记 |
|---|---|---|---|---|
| `materialClassPreferenceMultiplier` | **×1.3** | 1.1–1.6 | 层一物件命中客户偏好**大类**时 | 🎛 |
| `relicEmotionalMultiplier` | **×2.0** | 1.5–3.0 | 层二遗物对**匹配个人客户**（怀旧一代/二代）+ 特殊文本 | 🎛 |
| `relicMismatchMultiplier` | **×0.8** | 0.6–1.0 | 层二遗物对**不匹配机构/三代客户** + 归档冷淡腔 | 🎛 |

- 委托文本**暗示大类、不点名**。读懂委托、专挑偏好大类 = 打得好。
- **客户分代**（火星个人客户）：移民一代（记得地球）/ 二代（只听父母讲过）/ 三代+（把地球当古董收藏）。同一封信，对一代是无价，对三代只是一个编号——**反差即讽刺**。

## 5. 结算公式（核心数值）

**单件收入：**
```
单件_i = round( baseValue_i × 状态系数_i × 偏好系数_i )
```
- `baseValue` 范围 **1–500**（🎛）；任务中**隐藏**，结算才揭晓。
- 状态系数：完好 1.0 / 一般 0.7 / 受损 0.4。
- 偏好系数：
  - 层一 = 命中大类 **1.3** / 否则 1.0
  - 层二 = 匹配客户 **2.0** / 不匹配 **0.8**
- 舍入：四舍五入（远离零）。负值先归 0。

**总收入：**
```
salvage = Σ 单件_i
```

**按结局给钱：**
```
成功（自愿撤离，任何收获）：money = salvage
失败（全员倒）            ：money = round( salvage × 0.5 )   ← failurePayoutRate = 0.5 🔒
```
> 失败时：已入车的货按 0.5 结算；**倒地瞬间手上还没入车的物品全部丢失**。

**结算还会扣：**
```
去污处理费 = 全队总感染暴露 × 1G        （见 §8）
每月安全基础设施成本 = 40G→120G        （见 §11，按地球恶化等级）
```

### 5.1 算一个完整例子（指定委托，客户偏好"家居烟火"大类）

| 物品 | baseValue | 状态 | 是否命中大类 | 算式 | 得 |
|---|---|---|---|---|---|
| 私人信件（层二，客户是怀旧一代→匹配） | 60 | 一般 0.7 | 层二匹配 ×2.0 | 60×0.7×2.0 | **84G** |
| 全家福（层二，匹配） | 40 | 完好 1.0 | ×2.0 | 40×1.0×2.0 | **80G** |
| 陶瓷摆件（层一·家居，命中） | 50 | 完好 1.0 | ×1.3 | 50×1.0×1.3 | **65G** |
| 住宅家具（层一·家居，命中，重物） | 120 | 完好 1.0 | ×1.3 | 120×1.0×1.3 | **156G** |
| 专业工具（层一·劳作，**不**命中） | 80 | 一般 0.7 | ×1.0 | 80×0.7×1.0 | **56G** |

- `salvage` = 84+80+65+156+56 = **441G**，自愿撤离 → 成功 → **441G**。
- 若结算时全队暴露合计 200 → 去污处理费 −200G；当月安全成本 −60G（设 Stage 2）→ 实得 **441 − 200 − 60 = 181G**。
- 若中途全员倒、只有信+全家福入了车：(84+80)×0.5 = **82G**（家具/工具/摆件在手上 → 丢失）。

### 5.2 议价（每局一次，结果锁定不可回退）

| 物品状态 | 与委托匹配度 | 客户反应 |
|---|---|---|
| 完好 / 一般 | 高匹配 | 让步：**+15–30%** |
| 完好 / 一般 | 低匹配 | 拒绝（价格不变） |
| 受损 | 任意 | 反向压价：**−15–25%**（锁定） |

- 不是随机：`disputeConcedeRate` ~**40%**（30–60%，作者按物品/客户组合设定）🎛。
- 压价时客户永远给一个礼貌、官腔、道德破产的理由（讽刺在语气，不在数字）。
- 合作协议：全队同时看到清单，商量好按谁、一次按下即对全队生效。

## 6. 危险等级（隐藏，纯时间驱动）

> **没有任务计时器**。危险等级是连续值 `danger_level` 0→100，约 **28 分钟**走完；4 个阶段是这条曲线上的离散标记。**全程不显示数字**，靠世界行为和音效感受。

| 阶段 | 触发（单趟） | 怪物行为 | 环境信号 |
|---|---|---|---|
| 勘查 Survey | 进入（前 8 分钟安全窗） | 固定巡逻、窄探测 | 安静、远处声响 |
| 活跃 Active | **8 分钟**起 | 巡逻变宽、反应变快 | 频繁怪声、灯不稳 |
| 追猎 Pursuit | **18 分钟**起 | 主动搜索、多刷新点激活 | 近处声响、building 压迫音 |
| 饱和 Saturation | **28 分钟**起 | 全楼敌对 | **货车撤离信号（喇叭+灯闪）** |

**饱和 → 强制撤离倒计时 60 秒**（🔒 唯一硬截止）：不上车 = 失败。

**阶段时长（🎛）：** 勘查 8min / 活跃 10min / 追猎 10min / 饱和倒计时 60s。

**多次往返惩罚（🎛 `multiTripPhaseAdvance`=1）：** 每次回车后重进，危险阶段 +1。
```
第1趟：勘查→活跃→追猎→饱和
第2趟：活跃→追猎→饱和（窗口压缩）
第3趟：追猎→饱和（很短）
```
→ 多趟是高风险策略，不是默认最优解。

**怪物活跃度** = `lerp(空闲, 狂暴, danger_level)` 在阶段内平滑上升。

## 7. 感染暴露（可见，每人独立，换成扣款）

**累积公式：**
```
每分钟暴露 = base_rate × danger_multiplier[阶段] × zone_factor[区域]
```

| 变量 | 值 | 标记 |
|---|---|---|
| `base_rate` | **3 / 分钟** | 🎛 |
| 危险倍率 danger_multiplier | 勘查 **×1.0** / 活跃 **×1.5** / 追猎 **×2.5** / 饱和 **×4.0** | 🎛 |
| 区域系数 zone_factor | 入口·走廊 **×1.0** / 中区 **×1.3** / 深区·目标 **×2.0** | 🎛 |

**例子：**
- 走廊待 5 分钟（勘查）：`3×1.0×1.0×5 = 15`
- 深区待 5 分钟（追猎）：`3×2.5×2.0×5 = 75`
- 第二趟（从活跃起）中区 5 分钟：`3×1.5×1.3×5 = 29`

**效果分级：**

| 暴露 | 效果 |
|---|---|
| 0–40 | 无（安全区） |
| 41–70 | 轻：视野暗角、轻微音失真 |
| 71–90 | 中：**移动 −10%**、视野变窄 |
| 91–100 | 重：严重妨碍移动/视野，强烈催你撤 |

**结算扣款：**
```
去污处理费 = 全队总暴露 × 1G     例：4 人共 240 → 人员去污处理（4人）：−240G
```
- **暴露 > 70 在深区捡物 → 该物降 1 档状态**（把"个人暴露代价"和"物品贬值"连起来：在深区久留 = 去污更贵 + 东西更不值钱）。
- HUD 上只有这一个数字指示器（防护服填充条 0–100），危险等级不显示数字。

## 8. 怪物 · 回声霉菌（Echo Mold）

- **形态**：1.8m 感染人形真菌宿主。**危险不在力气，在它偷录并回放你们对讲机里的人声**，用队友的声音从错误方向喊"我找到了，过来！"引散队伍。
- **伤害**：接触/啃咬周期掉血（**非秒杀**），血空 = 倒地（可被队友救起）；**全员倒 = 失败**。
- **4 状态**：游荡 Roam → 诱骗 Lure → 追近 Hunt → 啃咬 Attack。
- **每图 1 只**（MVP）。
- **信号色**：amber-orange `#FF6A00` 孢子眼；第一警报是行为/听觉（孢子噗噗声、回放的金属失真），近距离才以眼点"确认"。**不关灯、不制造黑暗事件。**
- **语音机制**：为每名玩家滚动缓存最近 `voiceWindow` 秒、至多 `maxClips` 段（FIFO）；库空用预置诱导词。每 `lureInterval` 秒从一个 ≥ `decoyMinDist` 的诱饵点放声。
- **危险联动**：活跃度随 §6 的 `danger_level` 上升。

> ❓ **待定数值**：`dmgPerTick / dmgTick / voiceWindow / maxClips / lureInterval / decoyMinDist` 尚未给默认值，需要和策划一起定。

## 9. 检视系统（2026-06-26 加）

- **交互**：持物时**按住右键举起、鼠标旋转**看细节（信封名字 / 照片里的脸 / 玩具磨损）；松开收回。
- **减速不定身**（保留撤离紧张）。
- **范围**：所有可捡物可举；只有**层二遗物**有可读细节。
- **不改价值**（🔒）——纯认知/情感，不是"鉴定"（鉴定是 A镜的活）。

## 11. 地图结构（和数值挂钩的地方）

- 全游戏 **6 张任务图**，共享一套模块化套件；当前聚焦 HQ + 3 张（烂尾楼 / 地下会所 / 货运站）。
- 每图 **3 个 hero room 锚点**：入口 / 中段 / 深区（相对位置固定，玩家跨局学会这张图）。
- **biome 户外接近层 → 室内核心**：下车在户外生物群落，走进室内拿货/遇险。
- **危险区映射锚点**（§7 zone_factor）：入口 ×1.0 / 中段 ×1.3 / 深区 ×2.0。
- **战利品按锚点递增**：入口 = 轻/中；中段 = 混合 + 1–2 重；深区 = 最高值 + 重物（双手抬）。**越深越值钱，但越脏越危险** —— 核心贪婪/风险杠杆。
- **每局随种子变化**：走廊连接拓扑、门开关、物品位置、怪物起点；**不变**：锚点位置、目标区、上车点。
