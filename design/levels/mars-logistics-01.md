## V3 房间化改版（2026-07-10）

旧版“一轴三段 + 主仓大厅”的实现已废弃：入口能看到过多地图、露天货场与夹层让
空间像关卡白盒而不像真实物流设施。当前 builder 改为连续房间链：

`落客坪 → 双门气闸 → 收货登记室 → 低顶维护走廊 → 分拣处理间 → 低顶走廊 →`
`货运办公室 → 低顶走廊 → 冷藏隔离间 → 低顶走廊 → 深区封存货舱`

- 相邻关键门横向错轴，入口不能直视深区；普通门洞 2m，深区门洞 2.8m。
- 每个房间入口都有横梁与地面材质阈值；走廊感知高度 2.4m，房间为 3.2–5.5m。
- Entry / Mid / Deep 的战利品价值与怪物压力同步递增。
- 旧主仓大厅、露天集装箱场、夹层、地下隔离扩建不再由 builder 实例化。
- 地图只保留 HQ 打印取得的工单；任务加载不再在落客点生成独立打印机。

## 虚构（接现有世界观）

雇主就是任务池里已有的**「火星 · 地球遗产征集事务所」**。这是他们在火星地表的
物流中转站——运营方破产后被法院**查封冻结**，一批已清点未清关的"地球遗产"货
还锁在仓里。委托：进站把指定货物取回来，按件结算。查封文书、冻结封条、清关
表格贴满墙——可疑市政公文支柱直接落地。奇观归任务图：HQ 破旧压抑，这里给
火星尘暴天 + 高大冷仓的尺度落差。

## 布局（一轴三段·约 42×26m 室内 + 小型室外落客坪）

```
            N（尘暴背景·不可进入）
  ┌─────────────────────────────────┐
  │  冷藏附楼      主仓库大厅        │
  │ (COLD, 暗+雾) (HALL, 8m 高)     │
  │  遗物级货箱    货架巷道×4        │
  │  怪物巢       翻倒货架/洒落货箱  │
  │               ┌──────────┐      │
  │               │办公夹层(2F)│     │
  │               │文件/轻货   │     │
  ├─── 气闸接待 ──┴──────────┴──────┤
  │  (AIRLOCK, 查封公告墙)           │
  └───────────┬─────────────────────┘
        落客坪(PAD)·van·尘暴外景
            S（玩家从这里进出）
```

- **动线**: 落客坪 → 气闸（读封条=教学 beat）→ 大厅货架巷道（主搜刮）→
  分支A 冷藏附楼（高价值+高威胁）/ 分支B 夹层办公室（轻货+俯瞰）→ 原路或
  大厅西侧破卷帘捷径回坪。
- **MonsterSeed ×3**: 冷藏深处（NEST）、大厅远端巷道、夹层。
- **LootAnchor ~28 个**: 货架层板/办公桌/散落货箱堆（LootSpawner 按局抽 10–14）。
- **锚点**: `MissionVanExitPoint`（坪上，van 视觉由 MissionMapFinalizer 落地）、
  `PlayerSpawnPoint`（坪侧）。任务 rig 其余件走 ScavengeMissionBootstrap 运行时补。
