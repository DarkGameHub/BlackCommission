## 0. 目标（一句话）

把"读不到内容"变成"**看得到痕迹**"。捡起物品可举到面前旋转端详——对**层二私人遗物**尤其重要："举起一件别人的遗物端详"本身就是私密、愧疚的体验。**纯认知 / 情感，不改价值。**

## 1. 核心交互

- 持握任意可捡物时，按住 **[检视键]** 把物品举到相机前；移动鼠标**旋转**物品；松开收回。
- 检视中**减速**（不完全定身），移动或松开即退出。
- **所有可捡物都可举起检视**；其中**层二遗物**带**可读检视细节**（信封收件人名字 / 照片里模糊的脸 / 玩具磨损 / 退回章），层一物件检视 = 看物件本身（纯沉浸）。

## 2. 不改价值（D4 locked）

检视**不影响结算 / 状态 / 状态判定**。它不是"鉴定"——鉴定是 A镜的活（`scavenging-item-system` Rule 6，看精确状态百分比）。检视只是"看清楚这是谁的东西"。**host 权威不介入**（不改任何同步状态）。

## 3. 联机

- 检视是 **owner 本地视觉行为**（每个玩家各自举起看），**不产生网络权威状态**。
- （可选，非 MVP）第三人称：把"举起端详"的姿势同步给队友，让别人看到你在端详某物——轻量姿势同步。

## 4. 程序接口

- `InspectController`（第一人称）：把当前 held item 临时移到相机前的 inspect anchor，吃鼠标旋转输入，松开还原。
- `ScavengeItemDefinition.inspectDetail`（层二）：检视时可读的细节（高分贴图区 + 可选一行短文本，如收件人名字）。
- **不新增网络状态**（除非做 §3 可选姿势同步）。

## 5. 对美术的要求（已同步进 `modeling-team-brief` §5.6）

- 层二遗物贴图**用满 256px**，关键细节（手写名字 / 脸 / 磨损 / 印章）在检视距离（≈0.3m）**可读**。
- 物品要有**合理的可旋转外形**：背面也要有贴图（会被转过来看），不能是只做正面的纸片。

## 6. 决策点（✅ RESOLVED — David 2026-06-26 全用推荐默认）

| # | 决策 | 我的推荐 |
|---|---|---|
| **D-I1** | 检视键位 + 检视时定身还是减速？ | 按住**右键**举起、鼠标旋转；**减速不定身**（保留撤离时的紧张） |
| **D-I2** | 检视范围：所有可捡物可举，还是仅层二？ | **所有可捡物可举**（沉浸一致），但**只层二有可读细节**——避免"只有重要东西能举"破坏沉浸 |
| **D-I3** | **结算留痕**：检视过的层二遗物，结算时多显示一行（玩家"认识"了它）？ | **做**——轻量且强化"你知道这是谁的"，让结算反差更扎 |
| **D-I4** | 第三人称"举起端详"姿势同步进 MVP 吗？ | **MVP 不做**，后续加；先保证本地检视手感 |
