## Purpose & Player Need

**目的（一句话）**：让玩家在任务现场亲手"读"一个死去陌生人的遗物——把它**拿到眼前、握着旋转**，看清它的**视觉痕迹**（磨损、模糊的脸、信封上的名字）与偶尔一两行私语，把一件战利品变成一个人。检视**只改变认知与情感连接，绝不改变价值**。

**玩家此刻想做什么**：他刚从黑暗里捡起一张照片 / 一封信 / 一张儿童画，想**看一眼**——出于好奇与同情，不是为了算钱。系统欠他的只是让这一眼"落地"成一个人性瞬间，而非一行属性。

**这是两拍情感结构的第一拍**。第一拍（本 spec）：现场，亲密、当下、握在手中的**视觉痕迹**。第二拍（`settlement.md` 的 `SettlementCardOverlay` + 客户使用备注，**本 spec 只交叉引用、不重写**）：结算台上火星客户冷漠的**用途反差**——同一封信，对怀念地球的一代是无价，对收藏地球的三代只是一个编号。**检视让你先在乎，结算才好刺痛。**

**没有它会怎样**：层二遗物（每图手工 3–6 件）沦为"看不出价值的捡纸"，浪费"地球遗物被消费"主题；玩家与死者之间建立不起连接，结算反差也就刺不痛。

**不可逾越的线（检视契约）**：
- **不改价值**——绝不是"必须做否则少赚"的负担；跳过检视零损失（保证玩家可以为活命而不读）。
- **不强制**——没有"必须检视才算完成"的目标物（沿用搜刮 D-G 无指定目标原则）。
- **揭示纯认知/情感**——可显露"对应的人"线索（`relic.targetPersonId` + 克制的 `relic.inspectDetail` 一两行文本），只作用于理解与共情，不解锁价值、不计完成度（D4 APPROVED）。

> 玩家来到这一刻，想要的不是"这值多少钱"，而是"这是谁、他怎么了"。检视唯一欠他的，是让他**在黑暗里、在当下、在手中**得到那个问题的一点点答案。

## Player Context on Arrival

**在哪、什么状态**：任务现场（当前烂尾楼）深处，光线昏暗、靠手电（`FlashlightController` 电量有限）。搜刮进行中——**重量 vs 价值**压力在身、**滞留时间→威胁升级**的时钟在走（现场威胁；指代见 §Open Questions），他可能背着层一 salvage、口袋有轻物、队友或在身边或散开。

**他刚做了什么**：准星刚停在可检视物上（变钠灯琥珀 + 一行纸色提示，沿用 `hud.md`），或已把一件**轻**遗物捡进手里。主对象是**层二遗物**（每图 3–6 件手工放置）。〔层一 salvage 也"能拿到眼前看但看不出值多少"——属 **v2**，MVP 不做，见 §States。〕

**情绪**：紧张、贪婪、被时间追。检视要求他**停下来、低下头、变脆弱**——这是对"往前冲"的刻意反拍（决策②）。这一下犹豫本身就是设计：读还是不读？谁来读、谁掩护？时钟还在走。

**新手 vs 老手**：新手在这里**第一次撞见**主题（"哦……这是个死人的东西"）；老手知道遗物不赚钱，却仍可能为一个匹配客户的强记忆点停下——也可能学会"收起来，回车上再读"（改日检视，v2）。两种玩家，检视都不惩罚。

## Navigation Position

**它是哪一层**：一个**第一人称、贴游戏世界（diegetic）的现场交互层**，不是独立屏幕、不是菜单。**叠加在实时任务视图上**——世界仍渲染、host 不暂停、现场威胁仍猎杀（决策②）。与 `mission-encounter-hud.md` 同构（"HUD 的遭遇*层*，不是新屏幕"）。

**两个进入来源**：
- **现场检视**（主路径，脆弱，**MVP**）：在危险现场把遗物拿到眼前当场看。
- **安全检视**（改日路径，决策②的退出口，**v2**）：把轻遗物收进口袋带回**车上 / HQ**，零威胁下重看；内容/价值与现场**完全相同**（不奖励也不惩罚拖延）。MVP 先保留"收进口袋"的退出口与数据，**重看 UI 延后**。

**它通向哪**：一个**叶交互**——从玩法进来、回玩法去，不分叉到别的屏幕。情感上的"姊妹"是**结算卡**（第二拍，`settlement.md`），靠 `relic.targetPersonId` 串同一个人，本 spec 不进入结算。

**它不接管什么**：不暂停、不接管整块屏幕——3D 握持**保留世界可见**，正是张力①选 3D 的理由：让"亲密现场"与"冷漠结算卡"在视觉语言上就分开。

## Entry & Exit Points

> 进入轻量、退出**即时且非阻塞**——脆弱状态必须永远有一键逃生出口（决策②）。

**进入（Enter）**

| 触发 | 前置 | 结果 |
|---|---|---|
| 看着可检视物 **hold F**（与 `E` 拾取分开；F 当前未占用——手电走热栏且已禁用） | 准星在可检视物上（已变琥珀+提示） | **拿到眼前**（抬到视线正前方），进入低头握持姿态 |
| 手里/口袋已有轻遗物，hold F | 持有该遗物 | 同上 |
| 安全区（车上/HQ）打开口袋遗物〔**v2**〕 | 处于安全区 | 平静版检视（无威胁、无脆弱） |

- **一拿到眼前即看到全部**：视觉痕迹 + 一两行可读文本一起呈现，**鼠标可旋转看不同面**（照片正反、玩具各面磨损）；无"先粗看→再凑近才显字"的分层（A2）。
- **轻遗物**（信/照片/画/日记/公文，`lightItemPocketSlots`）：可握、可旋转、可入袋改日看〔v2〕。
- **层一 salvage**：可手持小物能拿到眼前粗看〔v2〕；**双手重物**（`CarrySystem.IsCarryingHeavy`，热栏锁定）不适用握持检视（抬不到面前），且**读不出价值**——检视对层一是次要功能。

**退出（Exit）——全部即时**

| 出口 | 触发 | 结果 |
|---|---|---|
| **收起** | 松开F | 放下，回正常玩法；新捡的留手里/入袋 |
| **打断逃/战**（脆弱逃生阀） | 任意 移动/冲刺/攻击/手电/热栏 输入 | **瞬间**退出去应对威胁——零延迟、零确认 |
| **收进口袋改日**〔v2〕 | 收纳键 | 轻遗物入袋，标记"未细看"，车上/HQ 可再检视 |
| **倒下掉落** | 检视中 HP→0（`PlayerHealth.IsDowned`） | 手持物按核心循环**掉原地、永久丢失**；姿态随倒地动画终止 |

- **被打断不丢东西**（除非倒下）：逃/战只是放下、不掉落——鼓励"先收手保命、回头再读"，不惩罚好奇。
- **联机**：检视是**本地视图状态**，host 不暂停、其余队员照常；第三人称下**队友能看到你低头握持的脆弱姿态**（B3，支撑"掩护我读信"）。只有"是否仍持有该遗物"走 server-authoritative。详见 Interaction / Events 节。

## Layout Specification

### Information Hierarchy

检视时玩家视线的优先级，从主到弱：

1. **遗物本体**（主）— 3D 模型，握在屏幕**中心偏下**（模拟低头看手中物），是注意力锚点。
2. **视觉痕迹**（次）— 遗物表面本身的磨损 / 模糊的脸 / 折痕，靠光照与材质读出，**不是 UI 叠层**（决策①掠射光"雕"出痕迹）。
3. **一两行可读文本**（`inspectDetail`）— 纸色小字，贴遗物旁，≥16px@1080p（沿用 `hud.md` 字号/纸色）；可含显露的"对应的人"线索（名字/称谓，来自 `targetPersonId`）。
4. **操作微提示**（最弱）— 屏底"拖动旋转 · 松开放下"，上手后可淡出。

> **世界仍可见、不接管全屏**（决策①核心）：四周任务现场保持**暗渲染 + 轻度压暗/失焦**突出遗物，但**不黑屏、不暂停、不全隐安全 HUD**——"亲密，但仍在危险中"。

### Layout Zones

基于 `hud.md` 的 1920×1080 / 16:9 锚点体系：

- **Zone-Relic（中心偏下）**：遗物 3D 握持位，占屏中部略偏下。
- **Zone-Detail（遗物右侧 / 下方）**：`inspectDetail` 文本块 + 可选"对应的人"线索行；纸色 TMP 小字。**screen-space 锚定**（遗物旋转时文字不随转，呈现 relic 整体信息摘要、非某朝面的贴图转录）；文字带**深色半透明底衬**（"撕边档案标签"语言、透明度 ~0.55，融入纸质档案美学、**非 UI 卡**）保障暗场景对比度（WCAG AA 4.5:1）。
- **Zone-Hint（屏底中央）**：操作微提示，沿用 `hud.md` 提示语法。
- **保留的安全 HUD（顶部 / 原位）**：检视是**脆弱态**，HP / 耐力 / 手电电量 / 威胁相关读数**不全隐**（可轻度淡化）——玩家此刻更需要知道自己的安危；准星可隐。

| 组件 | 类型 | 来源 / 约束 |
|---|---|---|
| 遗物 3D render | 世界空间·握持位·受现场光照·可旋转 | 真模型（v2） / 占位件（MVP 开发） |
| 世界压暗·景深层 | 后处理 / 叠层 | 突出遗物、**不黑屏** |
| Detail 文本块 | TMP UI（纸色） | **可本地化 UI 文本，非烤进贴图**（A1 / Loc） |
| inspectDetail 底衬层 | 深色半透明（~0.55）"撕边档案标签" | 暗场景对比度保障；颜色不单独承载信息 |
| "对应的人"线索行 | TMP UI（可选） | 来自 `relic.targetPersonId` |
| 操作微提示行 | TMP UI | 沿用 `hud.md` |
| 保留的安全 HUD | 既有 `MvpHud` 元素 | 检视时不全隐 |

## States & Variants

| 状态 | 触发 / 条件 | 可视 · 行为差异 | MVP? |
|---|---|---|---|
| **现场检视·脆弱**（主态） | 危险现场 hold F | 低头握持；世界暗可见不暂停；安全 HUD 保留；**视角锁定、站定**（移动键→瞬间打断、还原视角）；视野被遗物占；第三人称低头姿态 | ✅ |
| **安全检视·平静** | 车上 / HQ 打开口袋遗物 | 同呈现，但无威胁、无脆弱、可静心看 | v2 |
| **轻遗物**（层二） | 信 / 照片 / 画 / 日记 / 公文 | 可握 · 旋转 · 入袋（v2）；有 `inspectDetail` | ✅ |
| **重 salvage**（层一） | 双手重物 | **不进**握持检视（抬不到面前）；读不出价值 | v2 |
| **联机·本地视图** | 任意 | 检视为本地视图态；host 不暂停、队友照常 | ✅ |
| **联机·队友可见** | 第三人称 | 队友看到你**低头握持**的脆弱姿态（B3，掩护语境） | ✅ |
| **被打断** | 任意 移动 / 战 / 手电 / 热栏 输入 | 瞬间急放下、回玩法、**不丢物** | ✅ |
| **倒地终止** | 检视中 HP→0 | 姿态随倒地动画终止；手持物掉原地、永久丢失 | ✅ |

> **脆弱的本质**：检视中视角锁定、视野被遗物 + 低头占据 → **看不清周围威胁**——这本身就是脆弱来源。**任意移动键 = 瞬间打断并还原视角**：所以检视期间你自然站定（不是被锁死罚站，而是"一动就退出"），随时可一键脱离。

## Interaction Map

| 输入 | 上下文 | 反馈 / 结果 |
|---|---|---|
| **准星悬停可检视物** | 现场 | 准星变钠灯琥珀 + "握着看（F）"纸色提示（沿用 `hud.md`） |
| **hold F** | 悬停可检视物 / 已持有 | 拿到眼前、进入握持检视态 |
| **保持 hold** | 检视中 | 维持姿态；松开即退出 |
| **鼠标移动 / 拖动** | 检视中 | **旋转遗物**看不同面（照片正反、玩具各面磨损）；视角锁定，非揭示门控 |
| **松开F** | 检视中 | 放下、回玩法（新捡的留手里 / 入袋） |
| **任意 移动 / 冲刺 / 攻击 / 手电 / 热栏** | 检视中 | **瞬间打断**、急放下去应对（不丢物） |
| **收纳键**〔v2〕 | 检视中（轻遗物） | 入袋、标"未细看"、可改日检视 |
| **受击 / HP→0** | 检视中 | 倒地终止、手持物掉落永久丢失 |

> 检视中鼠标从"控制视角"切到"旋转遗物"——**不能环顾**正是脆弱所在；任意移动键松回视角是逃生阀。
>
> **hold 语义**：进入 = **即入**（按下立即起抬手动画，**无最短时长、无 B2 进度条**——0.25s 动画本身就是"有意按住"的反馈）；维持 = **持续按住F**（Hold 型，松手即退；区别于电闸的 timed-hold）。**已握持遗物时无需准星对准**，随时 hold F即可"举起来看"。
> **a11y**：设置提供 **Toggle 模式**（按一下进入、再按退出，免持续握按）——见 Accessibility 节。

## Events Fired

> 检视是**本地视图状态**（host 不暂停）；只有"持有权"与"第三人称姿态"走网络。

| 事件 / 状态 | 范围 | 用途 |
|---|---|---|
| `InspectStarted(relicId)` | 本地 owner | 进入检视态、起抬手动画 |
| `InspectEnded(reason)` | 本地 owner | 退出；reason = Release / Interrupt / Downed |
| `RelicPersonRevealed(targetPersonId)` | 本地 owner | 显露"对应的人"线索（纯认知 / 情感，**不改价值、不计完成度**） |
| `IsInspecting`（`NetworkVariable<bool>`） | **server-auth，广播** | 驱动第三人称低头握持姿态给队友（B3 掩护语境） |
| 持有权 / 拾取 / 掉落 | **server-auth**（复用现有搜刮同步） | "是否仍持有该遗物"的权威；倒地掉落沿用现有 |

- **不广播**旋转 / 视角：纯本地视图，省带宽。
- **不触发**任何 value / reward 事件——检视与经济解耦（契约）。

## Transitions & Animations

- **进入·拿到眼前**：遗物从持握位 / 拾取点抬到视线前，~0.25–0.35s ease-out，伴轻微低头：**相机俯仰 ≈ -8°~-12°**（前庭友好）+ 手部把遗物抬入 Zone-Relic。克制，不夸张。**Reduced Motion 开启时相机俯仰归零**（只保留手部动画）。
- **旋转**：遗物平滑跟随鼠标（轻惯性）、无吸附，自由看各面。
- **退出·收起**：放下 ~0.2s，回正常持握 / 视角。
- **退出·被打断（急放下）**：~0.1s 急放，**立即交还移动 / 视角控制**——脆弱逃生必须跟手。
- **倒地终止**：姿态被倒地动画覆盖；遗物脱手掉落（落点 / 物理）。
- **基调**：沿用 `hud.md` 与项目克制基调；无花哨特效。痕迹靠掠射光"被雕出"属渲染 / 材质范畴，这里只定**时长与姿态**。

## Data Requirements

检视消费的数据（字段沿用 `scavenging-two-tier-revision-2026-06-26.md` §7）：

| 数据 | 位置 | 说明 |
|---|---|---|
| `tier`（Salvage / Relic） | `ScavengeItemDefinition` | 检视主要面向 Relic（层二） |
| `isInspectable`（bool） | `ScavengeItemDefinition` | 是否可握持检视（层二=true；层一小物 v2） |
| `targetPersonId` | `ScavengeItemDefinition`（层二） | "对应的人"，串联结算第二拍（`settlement.md`） |
| `inspectDetail` | `ScavengeItemDefinition`（层二，可选） | **localization key**（非 raw 文本、非烤贴图）+ 可选线索文本 |
| 当前检视态 | 运行时（不持久化） | `currentRelicId` / 旋转 quaternion（本地） |
| `IsInspecting` | 运行时 `NetworkVariable<bool>` | server-auth，第三人称姿态 |

- **检视绝不写** value / condition / reward 字段（契约：不改价值）。
- 视觉痕迹（脸 / 磨损）= 模型 / 贴图资产，不是数据字段（见 `modeling-team-brief.md` §5.6）。

## Accessibility

> 沿用 `hud.md` 既有 a11y 基线（色彩非唯一信息通道、字号 ≥16px@1080p、减弱屏闪开关）。检视层新增 / 强化：

| 项 | 级别 | 要求 |
|---|---|---|
| **Hold → Toggle 替代** | 必须 | hold F对运动障碍玩家有伤害风险；设置须提供 Toggle（按一下进入、再按退出，免持续握按）。依据 Game Accessibility Guidelines。 |
| **inspectDetail 对比度** | 必须 | 纸色小字在动态暗场景无法保证 WCAG AA 4.5:1 → 必须有深色半透明"撕边档案标签"底衬（见 Layout）。 |
| **Reduced Motion** | 建议 | 进入低头的相机俯仰（-8°~-12°）并入 `hud.md` 减弱屏闪同一设置项；开启时俯仰归零、只保留手部动画。 |
| **inspectDetail 文本缩放** | 建议 | 基线 ≥16px@1080p；检视文本是情感核心，可设独立缩放 1.0× / 1.25× / 1.5×（与全局字号分离）。 |
| **颜色不单独承载** | 符合基线 | inspectDetail 为纯文字、无颜色编码状态，合格。 |
| **无光敏闪烁** | 确认 | 急放（0.1s）、倒地脱手须确认无全屏闪光；与受击红闪分离。 |
| **键鼠重映射** | 确认 | hold-to-inspect 绑定须可重映射到任意键；持续按压期间另一手自由移动（打断 / 逃生）。 |

## Localization Considerations

- `inspectDetail` 与"对应的人"线索 = **localization key + string table**（TMP 渲染），**绝不烤进遗物贴图**（A1 / G1）。
- 视觉痕迹（脸 / 磨损 / 折痕）= 贴图 / 几何，**无需翻译**。
- 文本长度随语言变化 → Zone-Detail 的"撕边档案标签"底衬须**自适应伸缩**。
- 字号 ≥16px@1080p（沿用 `hud.md`）+ 可选独立缩放（Accessibility）。
- 游戏内 fiction 编号 / 日期（如 `2098-XXX`）可固定不翻；真需读者理解的句子走 key。

## Acceptance Criteria

| # | 类型 | 标准 |
|---|---|---|
| AC1 | 逻辑（EditMode） | hold F → `IsInspecting=true`、遗物入 Zone-Relic；松开 → 退出 |
| AC2 | 逻辑 | 检视中任意 移动 / 攻击 / 手电 / 热栏 输入 → <0.1s 退出，**不丢遗物**（非倒地） |
| AC3 | 逻辑 | 检视中 HP→0 → 退出 + 手持物**掉原地、永久丢失**（沿用倒地掉落） |
| AC4 | 逻辑 | 检视**不修改** item value / condition / reward（前后断言相等——契约） |
| AC5 | 联机 | owner 检视 → 其他客户端 `IsInspecting` 同步 true（server-auth）；host **不暂停**、队友照常 |
| AC6 | 视觉 / 手感（Play 验） | 3D 握持旋转跟手；低头俯仰 -8~-12°；底衬保对比度；世界仍可见**不黑屏** |
| AC7 | a11y | Toggle 模式可用；reduced-motion 俯仰归零；文本缩放生效 |
| AC8 | 揭示 | 层二遗物检视显露 `targetPersonId` 线索 + `inspectDetail` 文本（localized），**不解锁价值** |
