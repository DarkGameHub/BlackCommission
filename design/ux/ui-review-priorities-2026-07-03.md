## 逐屏评审

### 1. 大厅(派工等待)— 🔴 P0-1
- **现状**: 940×620 绿色 WaitingTerminal 大板 + QuickNetworkUI IMGUI 覆盖层。全游戏唯一
  还停在"工程调试面板"质感的必经屏;还是联机首因印象(朋友加入第一眼)。
- **风格归属**: 盖章公文卡(lobby.md 已定稿:派工名单)。
- **方向**:
  - 屏中央纸卡:市政青页眉「派 工 名 单」+ 右侧**房间码琥珀大字**(host 被问最多的一件事);
  - 卡体固定 4 行工号槽(01-04):马甲色条+名字+「负责」青章;空位=「(空缺)∙∙∙」点线;
  - 自己行内 ‹●○◌○› 快速换色(撞色=◌置灰),「更换工装」小字钮进选人场景;
  - 他人行尾 [静音] / host [按住除名 0.8s 墨条](按住=签字既有模式);
  - 卡底 `[Enter] 确认到岗,进入办公室` + 角落装饰「成立」红章;
  - **退役**: WaitingTerminal 面板、QuickNetworkUI HostWaiting 层、连接前旧色板选择器。
- **实施注意**: 两个架构旗标(色板独占 ServerRpc、除名 reason 标记)在 spec Data 节。

### 2. ESC 设置菜单 — 📐🔴 P0-2
- **现状**: 功能性 IMGUI(音量/伽马/灵敏度/退出),零设计语言;是**每个玩家都会碰**的屏。
- **风格归属**: 盖章公文卡(main-menu spec 子页表已定身份:「偏好登记表」)。
- **方向**:
  - 纸卡表单:每项设置=表格行(标签墨字+值右对齐),滑条=**墨条+卡尺刻度**(不是发光条);
  - 分区:显示(伽马/亮度)/ 音频 / 操作(灵敏度)/ **辅助功能**;
  - **辅助功能区收编全部欠账开关**(各 spec 悬空的承诺): 减弱动效(章不砸落/墨条不呼吸/
    检视俯仰归零)、检视 Hold→Toggle、减弱屏闪(受击红闪→四边红框脉冲)、按住改双击;
  - 退出到主菜单=「离岗单」二次确认小卡(与主菜单同语法);
  - 先补一页 quick 设置 spec(半天),再实施(一天)。

### 3. 办公电脑终端 — 🔧 P1-1
- **现状**: CRT 气质对(单色绿/反白/扫描线),结构不对:长面板一坨,无页签,无账本。
- **风格归属**: CRT 终端绿(它是全游戏唯一"大音量信息面",别的屏都在给它让路)。
- **方向**:
  - 顶栏 `BC 办公管理系统 v2.1` + 状态条(资金负数=反白`!`/债务/执照/HOST 态)常驻;
  - **页签行 `[1]委托文件 [2]采购目录 [3]公司账本`**,数字键直达,切换=一帧扫描线闪(无缓动);
  - 委托文件页: 委托表(编号/名称/委托人/报酬/状态)+选中行详情块+待结算反白块置顶;
  - 采购目录页: F1-F4 行+持有数;待结算未领→整页「采购冻结」蒙层;
  - **账本页暂缓**: 前置=逐单结算历史存储 ADR(technical-director),出了 ADR 再实施;
  - 红线: 永不显示声望/办公室等级/收购压力(GDD 禁令)。

### 4. 任务 HUD(含怪物遭遇层)— 🔧📐 P1-2
- **现状**: 功能全(VITALS/热栏/准星/目标行/受击/倒地),但 spec 是塔楼时代的;
  三只怪上线后遭遇层零设计(mission-encounter-hud 13/15 节空白)。
- **风格归属**: 现场工单(墨迹+纸条,紧急时印章红换档,回落归位)。
- **方向**:
  - **先修 spec 再动代码**: hud.md 信息清单按搜刮循环重排(密封完整度→舱位/口袋;
    生态柱→双手重物通用);
  - 遭遇 HUD 补写核心裁决: **不显示任何怪物位置/状态**——回声菌恐惧=「你的声音是危险」
    (开麦指示已有=§1 两硬需求已落),圣像=纯 diegetic(红眼+冻结本身即反馈,HUD 零新增),
    追击警报走 A3 通知行(印章红+文字,声音双通道);
  - 工单行 A1/A2 语法照旧(状态切换整行刷新+0.6s 琥珀高亮)。

### 5. 怪物图鉴 — 📐 P1-3
- **现状**: 有入口有面板,内容裸奔,无 spec(队列第 6 屏)。
- **风格归属**: 盖章公文卡的变体——**「案卷卷宗」**。
- **方向**: 每只怪=一页市政档案(编号+现场素描+已证实行为条目+涂黑段落);
  见过/受害过才解锁条目(earned-precision 规则用在知识上);未知怪=空白卷宗+「待补录」章。
  先 /ux-design 出 spec 再实施。

### 6. 语音指示器 — 🔧 P2
- **现状**: 黑 pill+彩色圆点,今日已挪右上角。功能正确(常驻开麦真相+首次同意)。
- **方向**: 形态保留(广播 on-air 惯例读得懂),微调进主题: 黑=dead-rubber 黑、LIVE=钠灯琥珀
  已对;加 1px 纸色描边使其"贴"在 HUD 语言里;文案走 MvpLocale(已是)。低优先。

### 7. 结算单 — ✅🔧 P2
- **现状**: 最成熟一屏(条款行/客户备注/章/逐件揭示今日已加)。
- **方向**: 只差内容: relic 揭示行副文案(现为占位)交 writer pass;空舱发车=一行
  「空舱返回——运输费照计」之类的讽刺行(文案 writer);失败态备注语气分池已有钩子;
  单号规则(BC-2098-NNNN 存档序号派生)与账本 ADR 一起定。

### 8. 票据条 + 派车单 — ✅🔧 P2
- **现状**: 叠印已修(标题/状态/墨条各占一行+左青标右红章),派车单本来合格。
- **方向**: 样式不动;剩的是**工程项**: 签发即异步加载+双门控开门(boarding spec 最大实施项)、
  到站渗光时序(熄火→0.5s 静默+squelch→门缝渗光——光色即地点签名)。

### 9. 检视面板 — ✅🔧 P2
- **现状**: 今日收口(撕边标签 0.55/文本/低头俯仰/操作提示)。
- **方向**: Play 手感走查后定: 世界压暗/轻失焦层(突出遗物,不黑屏——决策①核心);
  准星悬停提示词「握着看(F)」接入 IInteractable hint;联机客户端文本(ItemId 同步)工程项;
  五类遗物差异化交互(翻信/翻页/翻面)= v2 不做。

### 10. Connecting 加载卡 — ✅ P2(验收)
- **现状**: 今日重做(纸卡+青页眉+墨字+活墨条+页脚)。开机走查确认字体/布局即可。

### 11. 主菜单 — ✅ P3(走查)
- **现状**: 底子最好(真 3D 办公室 CRT+纸卡子页)。
- **方向**: 逐条验收 spec AC: 输错码「驳回」红章态、无存档时「继续营业」墨淡不可选、
  720p 纸卡不裁切、推镜无黑屏;行宽弹性(英文+40%)记 loc 债。

### 12. 更换工装场景 — ✅ P3(走查)
- **现状**: 按 mockup v3 已建(暖厅/冷窗/逆光剪影)。
- **方向**: 验三点定稿(暖奢厅/大冷窗/对比即讽刺)+撞色置灰;不加新功能。

### 13. HQ 状态纸条 — ✅ 完
- 今日改毕: 纸条语法+无事不显示+待领结算侧标转红。不动。

### 14. 货舱条 — ✅ 完
